# Clothing Marketplace(Pastimes) POE

## Project Description

This is a Clothing Marketplace web application developed using PHP and MySQL for the Portfolio of Evidence (POE).

The system allows:

- Customers to browse and buy clothes.
- Customers to add, update and remove items from a shopping cart.
- Sellers to submit clothing items for sale.
- Administrators to manage products and users.
- Administrators to communicate with buyers and sellers.

---

## Software Requirements

The following software is required:

- Visual Studio Code
- XAMPP
- PHP 8+
- MySQL
- Web Browser (Chrome or Edge)

---

## How to Run the Project

1. Install XAMPP.

2. Start:

- Apache
- MySQL

3. Copy the project folder into:

```
xampp/htdocs/
```

Example:

```
xampp/htdocs/Pastimes
```

4. Open your browser and visit:

```
http://localhost/Pastimes
```

---

## Database Setup

1. Open:

```
http://localhost/phpmyadmin
```

2. Create a database called:

```
clothingStore
```

3. Import the SQL file located at:

```
database/clothingStore.sql
```

---

## Database Files

The SQL file is located inside:

```
database/
```

Example:

```
database/clothing_marketplace.sql
```

---



## Important Notes

- Start Apache and MySQL before running the project.
- Seller requests are reviewed by the administrator.
- Images are stored inside the uploads folder.
